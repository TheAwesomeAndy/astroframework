# Noetic Atlas — Development Roadmap

## Stage 0 — Foundation

- Canonical chart fixture
- Static browser prototype
- Product/framework naming
- Repository architecture
- Explicit epistemic contract

## Stage 1 — Graph kernel

Deliverables:

- TypeScript project scaffold
- canonical JSON schema
- aspect calculator
- traditional ruler table
- generic dispositor graph
- SCC detection
- house-ruler tracing
- aspect matrix
- unit tests against canonical specimen

Exit criterion:

The canonical specimen is reproduced from planetary positions without hard-coded aspect or topology results.

## Stage 2 — Astronomy integration

Deliverables:

- ephemeris adapter
- timezone/location normalization
- birth chart calculation
- transit calculation
- applying/separating state
- provenance/version records

Exit criterion:

A new chart can be generated from birth data and every displayed position is traceable to the astronomy adapter.

## Stage 3 — Life Spectrum

Deliverables:

- time-series generator
- transit activation model v0.1
- long-range heat map
- exact-hit markers
- station markers
- house activation lanes
- zoom from decades to days
- event annotations

Exit criterion:

A 30-year timeline is navigable without using a transit wheel.

## Stage 4 — Traditional timing

Deliverables:

- annual profections
- lots
- zodiacal releasing
- nested temporal regimes
- synchronized visual overlays

Exit criterion:

The Life Spectrum can show continuous transit activation and discrete Hellenistic time-lord regimes in one coordinated interface without conflating them.

## Stage 5 — Conversational navigation

Deliverables:

- structured UI command API
- AI tool schema
- compare-date command
- trace-ruler command
- explain-edge command
- interpretation provenance
- source model labels

Exit criterion:

The AI can answer "why" questions by changing the visualization and citing computed paths, rather than relying on free-form prose alone.

## Stage 6 — Comparative models

Deliverables:

- Hellenistic configuration profile
- Jyotish adapter
- modern/transpersonal adapter
- visible model toggle
- cross-model comparison mode

Exit criterion:

The same astronomical chart can be rendered under different astrological rule systems without hidden rule mixing.

## Stage 7 — Life Space research

Deliverables:

- stable feature vector
- normalization strategy
- PCA baseline
- UMAP exploratory view
- recurrence plots
- state similarity search

Exit criterion:

Every dimension entering the embedding has a documented semantic meaning and a reproducible calculation.

## Stage 8 — Productization

Deliverables:

- user accounts
- chart storage and deletion controls
- saved explorations
- professional client workspaces
- report export
- subscription system
- telemetry designed around comprehension, not addictive engagement

## Stage 9 — Research program

Studies:

- traditional wheel vs Natal Field
- ruler-path tracing accuracy
- comprehension speed
- cognitive load
- expert vs novice performance
- longitudinal pattern recognition

The research program should distinguish visualization efficacy from claims about astrological causation.
