# UI Consolidation Plan

The live application preserves capabilities, not historical release shells as visible nested interfaces.

## Frozen UI rule

```text
one current application shell
→ one deterministic chart state
→ many coordinated projections
```

Historical HTML surfaces remain in the repository for regression/history, but the public application does not embed them recursively.

The unified app:

- embeds only the deterministic visual core (`prototype/index.html`) as the chart-calculation authority;
- exposes current capabilities through one navigation system;
- renders energetic analysis, graph findings/metrics, resonance, relational condition, House River, compound condition, proof, and integrity as sibling panels;
- preserves existing computational modules and rule models;
- removes visible stacked version headers and nested release wrappers;
- gives every non-chart panel its own scrollable viewport;
- remains responsive on mobile and desktop.

Historical release surfaces are implementation history, not UI chrome.
