# Noetic Atlas — Accepted Long-Range Research Architecture

Status: **accepted project architecture** beginning with the v0.4.6 research track.

This document governs the order in which ambitious mathematical and astrological ideas may enter Noetic Atlas. It is intentionally dependency-ordered rather than calendar-ordered.

## Central research identity

The distinctive claim of Noetic Atlas is not that it escapes the flat natal wheel. The distinctive claim is that it separates:

```text
observation
→ astrological rule
→ derivation
→ structural mathematics
→ controlled comparison
→ null testing
→ replication
→ provisional interpretation
```

so that those layers can no longer collapse into one sentence.

> **The mathematics should not manufacture meaning. It should make claims testable.**

This principle complements the existing constitutional rules:

```text
one chart state → many explicit models → many coordinated projections
Operational ≠ Experimental ≠ Discovery
Detect → Describe → Compare → Test → Replicate → Interpret
```

## Five strata

### A — Astronomical substrate

Role: trustworthy coordinates and astronomical provenance.

Current foundation includes the existing deterministic birth-time pipeline, longitudes, velocities, ASC/MC, Whole Sign placement, and provider provenance.

Near-term enrichment may include:

- higher-precision coordinate validation where needed;
- declination;
- additional validated celestial bodies;
- explicit coordinate-system metadata;
- provider/version provenance for every astronomical quantity.

The astronomical substrate is deliberately boring. It is not a place for interpretation.

### B — Rule models

Role: named, versioned astrological models applied to the same astronomical state.

Existing Operational / Experimental / Discovery regimes and Research Hypothesis Packs are the governing mechanism.

Every rule model must state:

- model identity and version;
- historical or experimental source;
- objects and geometry it consumes;
- exact predicates/formulas;
- exclusions and deferred variants;
- whether it is Operational, Experimental, or Discovery.

Alternative rulerships, aspect policies, condition variants, yogas/configurations, field kernels, and historical reconstructions belong here as explicit models. None may silently rewrite another model.

### C — Structural mathematics

Role: derive inspectable mathematical objects under an explicit model `M`.

Near- and medium-term objects may include:

- directed and undirected graphs;
- strongly connected components and basins;
- House River routing;
- typed motifs;
- hypergraphs for multi-body configurations;
- formal configuration grammars;
- harmonic/circular descriptors;
- spectra and persistence descriptors;
- explicitly experimental scalar/vector representations;
- formal fields such as `Φ_M(x)` under named kernels.

Every structural object must remain traceable to the state and rule model that generated it.

A mathematical structure is not, by itself, a spiritual, psychological, causal, or physical fact.

### D — Research inference

Role: ask whether a detected structure differs from an explicit comparison class.

v0.4.6 begins this layer with plural deterministic null models. Later work may add:

- astronomy-faithful ephemeris controls;
- real natal-population baselines;
- stratified cohorts;
- external outcomes;
- preregistered or frozen metrics;
- replication across independent cohorts;
- model comparison and sensitivity analysis.

Research inference must distinguish at least:

```text
unusual under null N
!= rare in a real natal population
!= associated with an external outcome
!= replicated
!= astrologically meaningful
```

### E — Human synthesis

Role: produce useful, labeled interpretive channels downstream of audited evidence.

Possible channels include Traditional, Energetic, Psychological, Mystical, Medical-history, Yogic/Ayurvedic, and Research lenses, provided each carries appropriate source and epistemic labels.

Human synthesis may consume verified structure and explicitly provisional research results. It may not invent geometry, silently merge models, or translate a low p-value into fate, power, rarity, or spiritual status.

Consumer synthesis becomes more trustworthy because the laboratory remains strict.

## Dependency order

The accepted long-range sequence is:

```text
Nulls
→ Formal Configurations / Hypergraphs
→ New Geometry
→ Experimental Models
→ Persistence
→ Population Baselines
→ Interpretive Research
```

This is a dependency graph, not a sprint schedule.

### Immediate

**v0.4.6 — Null Model Laboratory**

Required characteristics:

- plural nulls rather than one generic random chart;
- metrics frozen before simulation;
- deterministic seeds;
- full provenance;
- explicit preserved/randomized properties;
- explicit scope limits;
- raw and adjusted Monte Carlo probabilities where appropriate;
- research-status updates limited to the null-comparison dimension;
- interpretation withheld;
- population frequency explicitly not measured.

### Next — Formal configurations and hypergraphs

Configuration detection should evolve from named checklists into predicate trees.

A configuration definition may contain:

```text
participants
spatial predicates
sign/house predicates
rulership predicates
condition predicates
orb policy
source/model identity
```

A multi-body configuration should be representable as a first-class configuration/hyperedge object so that proof, condition, discovery, and later null tests can attach to the configuration itself.

### Then — hidden geometry

Priority before speculative continuous field topographies:

1. declination and parallels/contra-parallels;
2. antiscia/contra-antiscia;
3. midpoints;
4. additional validated geometries with explicit coordinate definitions.

These add new inspectable predicates without requiring a metaphysical field equation.

### Then — experimental model laboratory

Alternative rulerships, historical variants, expanded aspect policies, harmonic descriptors, field kernels, and other theoretical models should be compared side by side against frozen controls.

No experimental model gains ontological priority merely because its visualization is compelling.

### Then — persistence

Once structural semantics are stable, investigate which properties persist across:

- model choice;
- orb policy;
- coordinate uncertainty;
- birth-time uncertainty;
- nearby parameter choices;
- competing field kernels;
- temporal activation where appropriate.

Persistence is a research descriptor, not automatic validation.

### Then — population baselines

Only after the descriptors and null contracts are stable should Noetic Atlas estimate how frequently structures occur in real chart populations.

Population work must record sampling frame, inclusion/exclusion rules, demographic/time/geographic structure, astronomical correlations, and uncertainty.

### Last — interpretive and learned research

Phenomenological associations, external outcomes, graph neural networks, learned embeddings, and other data-driven models belong late in the sequence.

Learned models amplify the epistemology of their inputs. Muddy graph semantics produce sophisticated mud.

## Field mathematics boundary

Noetic Atlas may define a formal field

```text
Φ_M(x)
```

under an explicit model `M` and kernel family.

Gradients, interference, phase relationships, extrema, persistence, spectra, or other properties are legitimate properties of that mathematical representation.

They are **not** presented as measured planetary physical energy unless independent physical evidence exists.

A future Field Laboratory should compare multiple competing kernels and ask which derived properties survive model choice.

No single field is permitted to become “the planetary energy field” by default.

## Harmonics boundary

Circular statistics and harmonic descriptors may be developed before harmonic interpretation.

For example,

```text
Z_k = Σ_j w_j exp(i k θ_j)
R_k = |Z_k|
```

is a legitimate descriptor under declared weights and object sets.

Statements such as “harmonic 5 means genius” or “harmonic 7 means mysticism” are downstream interpretive hypotheses and require the same compare/test/replicate lifecycle as any other Discovery claim.

## Scalar-output boundary

Scalar outputs are allowed when the scalar is itself the historical or experimental object under study and is fully decomposable.

Examples:

- a historically reconstructed weighted scoring algorithm under an explicit table;
- a registered concentration index;
- a graph statistic;
- a harmonic magnitude;
- a null-test statistic.

Forbidden pattern:

```text
strength = 83.7
therefore this planet rules the chart
```

No hidden scalar may become ontology.

Condition should remain decomposable into primitive, relational, compound, and future explicitly named components.

## Geometry before metaphysics

When a simpler geometry can create a new falsifiable predicate, prefer it to a more speculative representation.

Therefore declination, antiscia, and midpoints precede continuous three-dimensional potential topographies.

## Product consequence

Personal mode should become simpler as the research laboratory becomes stricter.

A consumer-facing statement may eventually say that a structure is:

```text
verified geometrically
+ derivable under model M
+ extreme under null N
```

while still saying:

```text
population rarity unknown
replication incomplete
interpretation provisional or withheld
```

That is more useful than poetic overclaim because the claim boundary is visible.

## Governing tension

Noetic Atlas does not have to choose between metaphysical curiosity and scientific skepticism.

The project keeps both in productive tension by requiring every layer to be inspectable, every model explicit, every experiment reproducible, and every interpretive claim provisional and reversible.
